# 📖 Project Overview

**VORTEX QuizMaster** is a modern quiz arena platform where users can **create, discover, participate in, and compete through interactive quizzes**.

The platform combines quiz creation tools, category-based discovery, difficulty filtering, timed challenges, score tracking, leaderboards, ratings, and personal performance analytics into one engaging learning environment.

Designed with a **premium dark-themed interface**, VORTEX focuses on usability, competition, performance, and an immersive quiz experience.

---

# 🎯 Platform Vision


# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Lalithkrish06/QuizMaster.git
```

## 2️⃣ Navigate to the Project

```bash
cd QuizMaster
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Start Development Server

```bash
npm run dev
```

The application will be available through the local development URL provided by Vite.
